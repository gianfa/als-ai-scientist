# Contributing

This repository is a published snapshot of the project: each release replaces its tree, so it does not take pull
requests. A change merged here would be overwritten by the next release.

## Issues are welcome

Open an issue for:

- a bug, with the command you ran, the output, and the commit of this repository;
- a scientific error: a claim, citation or number that does not match its source;
- a gap in the documentation or in the setup on a fresh clone.

For a failed run, attach the run's `state.json` and the report of the failing phase from
`experiments/<RUN_ID>/results/`. Do not attach papers, datasets or API keys.

notes in `docs/package-overview.md` and the test commands in `README.md` are the starting point.
